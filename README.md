# ResQMech – Roadside Breakdown Assistance Application 🚗🔧

## 📌 Project Overview

ResQMech is a mobile application developed using React Native with Expo to provide quick and reliable roadside assistance during vehicle breakdown situations. The application directly connects drivers with nearby mechanics in real time without involving third-party service centers.

The system helps users request immediate assistance, share their live location using Google Maps, track mechanics in real time, and provide ratings and feedback after service completion. Firebase is used for authentication and real-time database management.

---

### 👤 User Functionalities

* User Registration & Login

* Ratings & Feedback

### 🔧 Mechanic Functionalities

* Mechanic Registration & Login
* Receive Service Requests
* Accept / Reject Requests

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone <your-github-repository-link>
```

### 2️⃣ Navigate to Project Folder

```bash
cd resq
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start Expo Development Server

```bash
npx expo start

OR

npx expo start --tunnel
```

### 5️⃣ Run the Application

* Install the **Expo Go** application on your mobile device
* Scan the QR code generated in the terminal or browser
* The application will open automatically in Expo Go

## 🔥 Firebase Configuration

1. Create a Firebase project
2. Enable Firebase Authentication
3. Enable Firestore Database
4. Add Firebase configuration keys inside the project
5. Connect Firebase with the React Native application

---

## 🗺️ Google Maps Configuration

1. Generate a Google Maps API Key
2. Enable Maps SDK for Android
3. Configure API key in the application
4. Enable device location services
